# 日本語で読む inkstone.nvim

これは **日本語の強調** と `inline code`、[リンク](https://example.org)を含む文章です。

> [!NOTE]
> BudouX で文節の境界を優先し、表のセルを読みやすく折り返します。

| 項目 | 説明 | 表示例 |
| --- | --- | --- |
| 句読点 | 行頭に句読点が来ないように折り返します。「括弧」の位置も考慮します。 | 「日本語」、文章。 |
| 文節 | 今日は天気がいいから散歩しましょう。 | BudouX |
| 濁点 | 結合文字の濁点を基底文字から分断しません。 | が / ｶﾞ |
| 絵文字 | 対応する結合シーケンスを途中で分割しません。 | 👩‍💻 🇯🇵 👍🏽 |
| 混在 | English と日本語、数字 123 が混ざった表です。 | Neovim の表示幅 |

```lua
local text = require('inkstone.text')
print(vim.inspect(text.wrap('「日本語」の表を、読みやすく。', 12)))
```

- [x] 日本語の表を描画する
- [x] 長いコードの装飾量を制限する
- [ ] 通常段落の文節リフロー
